# GNT Construction Website Design Ideas

<idea>
**Design Movement**: Classic American Craftsman — Heritage Industrial
**Core Principles**:
1. Warm, earthy tones evoking stone, timber, and mountain landscapes (matching the Utah/Cache Valley setting)
2. Structured two-column layout: main content left, sidebar navigation right — faithful to the original
3. Typography that balances authority with approachability (serif display + clean sans body)
4. Photography-forward design with the three project images as hero banner

**Color Philosophy**: Deep teal-green (#1a6b5a) as primary brand color (matching the original logo's teal), warm gray (#666) for body text, off-white (#f5f5f3) for backgrounds. The palette evokes reliability, nature, and craftsmanship.

**Layout Paradigm**: Faithful recreation of the original — top banner with three project photos, then a two-column layout with main content area on the left and sidebar with logo + navigation on the right. Footer with copyright.

**Signature Elements**:
1. Three-panel photo banner at the top showing completed projects
2. Sidebar navigation with teal accent on active items
3. Italic script tagline "A trusted resource since 1972."

**Interaction Philosophy**: Clean, functional. Hover states on nav items with teal highlight. Minimal animation — this is a professional construction company site.

**Animation**: Subtle fade-in on page load. Nav items with smooth color transition on hover.

**Typography System**: 
- Display: Georgia or similar serif for headings
- Body: MS Sans Serif equivalent (Arial/sans-serif) for body text
- Tagline: Italic serif for the "A trusted resource since 1972." line
</idea>
